# RinCode desktop v0.1 shared contract

Native macOS Electron application; React renderer, real existing Python runtime. Source lives in ui-desktop and new rincode/cli/desktop_server.py. No TUI modifications. Keep secrets out of renderer. Chinese UI with warm off-white palette, quiet Codex-like project/session sidebar, conversation, tool activity cards, composer, real confirmations and clarifications.

Renderer API is ui-desktop/src/bridge.d.ts, frozen across modules. Host persists project directories in Electron userData, id stable. addProject uses native directory dialog. connect starts one active project runtime (switching closes previous runtime; UI disallows project/session switch while a turn runs). rpc is allowlisted, events tagged projectId. Host emits method 'backend.status' with BackendStatus params. Other RPC notifications forwarded unchanged; stream method='event', params={subscription_id,event:{type,payload}}. Renderer filters subscription ID. Never infer completion from turn.send accepted.

Python entry: python -m rincode.cli.desktop_server, cwd=project. Generate random token, listen 127.0.0.1:0, print exactly one ready JSON line {"address":"127.0.0.1:port","token":"..."} and flush before runtime redirects stdout. Accept one connection, reuse _run_rpc_server_until_done(conn,token,deadline,proc_done). stdin EOF/SIGTERM sets proc_done; no zombie. Host passes stdin pipe open and closes on stop, with bounded TERM/KILL fallback. Host uses explicit RINCODE_PYTHON if set, else source repo .venv/bin/python, else python3. Host locates repo root based on app path; packaged local .app requires embedded local sourceRoot marker/build metadata. PYTHONPATH includes sourceRoot for worktrees. Token first line over socket, then JSON-RPC newline framing. handshake system.hello within 5s.

RPC core: session.list {} -> {sessions:[{id,title,message_count,preview,started_at,source}]}; session.create {} -> {session_id,info}; session.resume {session_id} -> {session_id,info,messages:[{role,text?,name?,context?}]}; turn.subscribe {session_key} -> {subscription_id}; turn.send {session_key,content,submission_id?} -> {turn_id,accepted}; turn.cancel {session_key}. Check schema/source for unsubscribe/delete. session.delete triggers confirm.request, so UI must remain responsive while promise awaits. confirm.respond {request_id,answer:boolean}. clarify.respond {request_id,answer:string}. Event token.delta/thinking.delta {text}; tool.start {tool_call_id,name,arguments}; tool.progress {tool_call_id,preview}; tool.complete {tool_call_id,result_preview,truncated,failed}; message.start, message.complete, error. Existing confirmations cover session deletion, not generic tool approval; expose honestly. No mock data in production or claimed E2E.

Ownership: host module owns ui-desktop/electron/**, package.json, scripts/**, tsconfig.json, index.html, README.md. Renderer module owns ui-desktop/src/** except frozen bridge.d.ts. Python module owns rincode/cli/desktop_server.py and tests/test_desktop_server.py. Integrator owns shared contract and final fixes. Each module commits owned changes in its own branch, reports commit and checks.

Build expected: npm --prefix ui-desktop install; npm --prefix ui-desktop run build; npm --prefix ui-desktop start; npm --prefix ui-desktop run package:mac -> local .app. Prefer esbuild for renderer and Electron CommonJS main/preload, Electron packager for local bundle. Dependencies React/react-dom, Electron, esbuild, typescript as needed. Renderer entry src/main.tsx. Host entry electron/main.cjs; preload electron/preload.cjs. Host tests node:test.
