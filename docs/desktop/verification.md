## Markdown 表格与项目会话树（2026-09-11）

原渲染器逐行输出段落，缺少表格规则。现支持表头、分隔行、列对齐、转义竖线和单元格内格式；代码围栏中的内容不会误识别为表格，流式未完成文本保持可读。新增 8 项解析与渲染测试通过，未引入依赖。

实际检查发现两个原有项目各有一条已落盘会话。旧侧栏把对话放在独立的当前项目区域，且未命名会话均显示“新对话”；现改成每项目下的可折叠会话树，支持直接选择非当前项目中的指定旧会话。只读历史目录入口列出已添加项目的桌面/TUI 会话，不启动其他项目的模型运行时，不修改旧会话；无标题时使用首条提问的简短展示名。

- 31 项 Node 测试、3 项历史目录 Python 测试、类型检查、构建和 macOS 打包通过。
- 独立临时项目的真实 Electron/Python 验证通过：A/B 各两条历史正确归属，跨项目打开非最新会话准确恢复；折叠展开不丢历史；追加历史后刷新当前与非当前项目均更新，当前选中会话保持；同配置重启仍有全部项目和 16 条已保存历史。
- 900×600 下项目会话树可滚动，添加与模型按钮持续可见；表格语义、表头和单元格检查通过，无 renderer 错误。
- 实际应用已更新并恢复原对话，确认报告的原表格已渲染为两列、七行数据。验证使用独立窗口读取原历史，未发送模型任务。
- 本轮未改变空白新会话的延迟保存语义，也未迁移属于其他目录的会话。
